# Security Policy

## Reporting a vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, use GitHub's private vulnerability reporting for this repository:

- Go to the repository **Security** tab → **Report a vulnerability**
  (GitHub Private Vulnerability Reporting), or
- Contact the developer/company privately via the channels listed on:
  - Application: https://ual.itisuniqueofficial.com/
  - Developer: https://jaydatt.pages.dev/
  - Company: https://www.itisuniqueofficial.com/

Please include a clear description, reproduction steps, affected version, and
any relevant (redacted) logs. Do not include third-party personal data.

## Scope

This policy covers the Universal App Lock application code in this repository.

Note: Universal App Lock is an independent third-party application and does not
use Samsung privileged/system APIs. It is not affiliated with Samsung Electronics.

## Supported versions

The project is pre-1.0 / in active scaffolding. Security fixes target the latest
`main` and the most recent release.

## Handling

We aim to acknowledge reports promptly, investigate, and coordinate a fix and
disclosure timeline with the reporter. See `docs/SECURITY.md` for the engineering
security boundary and rules.
